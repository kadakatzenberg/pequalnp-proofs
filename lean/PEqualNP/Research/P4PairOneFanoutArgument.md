# One-fanout obstruction for two disjoint P4 paths

## Claim and status

Let G be two disjoint paths 0-1-2-3 and 4-5-6-7. Let F be the OR of the six edge terms x_i AND x_j. Its exact fan-in-at-most-two AND/OR/NOT circuit size, counting every gate, is nine. Below is a human mathematical proof, including a direct lower-bound argument that does NOT rely on the earlier 1,439,225-line DRUP trace. The nine-gate upper bound is already Lean-checked in P4PairExactWitness.lean. Two auxiliary finite obstructions are Lean-checked in P4ReadOnceObstruction.lean and P4PairSharedSupport.lean. The entire graph-to-circuit normalization is NOT yet formalized in Lean, and this is NOT an official desk theorem or a novelty claim.

## Proof

1. All eight inputs are essential. For a hypothetical at-most-eight-gate circuit, take the output-ancestor DAG, ignoring the second listed input of NOT, invalid/forward references (which read false), and duplicate predecessor references. Let g be the number of gates in this DAG. All eight input vertices belong to it. Every non-output vertex has at least one outgoing dependency edge; gates have at most two distinct real predecessor edges. Hence 8+g-1 <= number of edges <= 2g, so g is 7 or 8.

2. If g=7 the DAG is a tree directed toward the output, every gate binary and every input used once. If g=8 and some gate has at most one actual predecessor, the same edge-count argument forces a tree with exactly one unary gate and no nullary gates. A unary identity can be removed; an AND with a false dummy operand would kill its descendant input dependence and is impossible because every input is essential and occurs only once. If the unary gate is NOT, any essential variable beneath it has negative polarity along its unique path to the output, contradicting monotonicity. Thus these cases give a monotone read-once formula. Fix all inputs on one component to zero and simplify constants; this would give a read-once formula for P4, impossible (see step 5).

3. The only remaining case has g=8, 16 distinct dependency edges, 16 vertices, and 15 non-output vertices. Every non-output vertex has outdegree at least one. Therefore exactly one wire h has outdegree two and every other non-output wire has outdegree one. All gates are proper binary AND/OR. The ancestor cone of h is itself a read-once tree (possibly just one input), on a nonempty set S of original variables. None of these variables or predecessor gates can have an outgoing edge bypassing that cone, because such an edge would create a second fanout. Consequently the whole function factors as F(x_S,x_out)=g_out(x_out,h(x_S)). Since the outside circuit is AND/OR, each nonconstant cofactor on S obtained by fixing the outside variables must equal h. In fact, the weaker observation suffices: any two nonconstant cofactors which both vanish on the all-zero S assignment must be equal even if the outer unary functions are arbitrary.

4. If S is disjoint from either P4, set all variables outside that P4 to false. The shared h becomes constant. The remaining circuit, after substituting that constant and pruning, is a read-once formula for the untouched P4, a contradiction. If S is all eight variables, F is a monotone nonconstant function of the read-once h alone, hence equals h, also impossible. For the remaining case, S is proper and meets both components. There are two possibilities:

   (i) S contains an internal edge. Since both connected paths are met and S is proper, some edge crosses from u in S to v outside S. Set all outside variables false (cofactor A), or set only v true (cofactor B). Both cofactors are nonconstant and vanish on zero S. An assignment with just u true gives A=false and B=true, contradiction.

   (ii) S is independent. Pick a vertex of S in each path; because every vertex has a neighbor and S is independent, both have outside neighbors. Set one of those outside neighbors true and all other outside variables false, giving two cofactors (one for each path). Both are nonconstant and vanish on zero S. A singleton true variable at the first selected inside vertex separates the cofactors because the components are disjoint. Again contradiction.

   The finite Lean theorem no_one_bit_factor in P4PairSharedSupport.lean checks all 224 proper mixed sets and directly proves no arbitrary Boolean h and outer function g can factor the truth table across that partition. Its witness-generation algorithm implements the two cases above; the theorem uses a general Boolean lemma that two unary maps vanishing on the same h(0) and each attaining true must agree. This is stronger than a mere sample check.

5. P4 itself is not read-once: its three minimal true sets are its edges. The root of a monotone binary read-once tree is OR or AND. An OR root would partition the graph's edges into disconnected nonempty variable blocks, impossible for connected P4. An AND root would make every prime implicant a union of one minterm from each child. Since every minterm has size two, each child has only singleton minterms and all its essential variables are included; thus the edge graph is complete bipartite across the partition. P4 is not complete bipartite. Alternatively, P4ReadOnceObstruction.lean rejects every one of 10,240 four-leaf binary AND/OR formulas using finite truth masks. Restricting a read-once AND/OR formula to constants preserves read-once after simplification.

All cases of an at-most-eight-gate circuit contradict one of these facts. A nine-gate circuit exists by the existing Lean witness. This completes the conventional mathematical argument for the specific graph. ## Generalization worth formalizing

For any graph with no isolated vertices, if at least TWO connected components have edge functions that are not monotone read-once, then the same argument gives circuit size >= n+1. In step 4, if S meets both hard components and contains an internal edge, a crossing edge forces the cofactor contradiction; if there is no crossing edge, S is a union of whole components and the shared read-once h would compute the union edge function, contradicting a hard component. If S is independent, one external neighbor from each hard component distinguishes the two slices. If S misses a hard component, restricting to it removes the single fanout. This argument does NOT prove unrestricted direct-sum additivity, nor the claimed bound with an arbitrary number of non-read-once components.

For forests with exactly two non-star components of cover number two and all other components stars, tau-k=2, so |E|+tau-1=n+1 and the above argument gives an exact additional uniform subclass. This is a mathematical consequence, not a checked general Lean theorem; novelty has not been established. Prior art: classical read-once/cograph characterization; Paul 1976 warns against unrestricted direct-sum additivity.
